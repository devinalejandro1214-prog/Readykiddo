# World Background Source Folders

Each world folder contains the clean base background as `base.png`.

When creating vibe versions for a world, place them in that world's matching vibe folder:

- `vibes/cozy/`
- `vibes/exciting/`
- `vibes/magical/`
- `vibes/silly/`
- `vibes/brave/`

Suggested filename for each finished vibe image:

```text
background.png
```

Example:

```text
space/base.png
space/vibes/cozy/background.png
space/vibes/exciting/background.png
```
